Laser Cut Box

Generates a laser-cut box with finger joints: one flat sketch of every panel, extruded to material thickness and assembled in 3D.

Steps

  1. Open or create a design, then run Laser Cut Box from the Solid tab's Create panel.
  2. Enter the outer length, width and height of the finished box.
  3. Set Material Thickness and Kerf to match the sheet and the machine you will cut on.
  4. Adjust Min Finger Width and Open Top until the preview looks right. Any problem with the values is reported in red at the bottom of the dialog, and OK stays disabled until it is fixed.
  5. Click OK. The panels land as separate bodies, with the flat Flat Layout sketch and all the features collected into one Box timeline group.
  6. To cut the parts, right-click the Flat Layout sketch and export it as DXF.

Properties

Length, Width, Height
Outer dimensions of the assembled box, measured over the panel faces.
Material Thickness
Thickness of the sheet. Panels are extruded to this, and it also sets the finger joint limits: a finger has to be at least two thicknesses wide, or the material cut back at a corner eats into it.
Kerf
Width of material the beam removes. Outlines are relieved by half this on each cut edge, so the parts come off the machine the intended size and the joints stay tight. Set it to 0 to draw nominal geometry.
Min Finger Width
A minimum, not an exact width. Each edge is divided into a whole number of fingers, so the real fingers are this wide or a little wider. Every edge gets at least three fingers, which on a short edge can override the request and force wider fingers than asked for.
Open Top
Omits the top panel, leaving a tray. The walls finish flush along the open edge with no fingers on it; the vertical corner joints still run the full height, so the corners stay interlocked.
Laser Cut Appearance
Cosmetic only. Paints the sheet faces as MDF and the cut edges dark, the way they come back off a laser. Turn it off for plain untextured bodies.
